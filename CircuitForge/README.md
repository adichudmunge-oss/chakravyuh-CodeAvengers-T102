# CircuitForge — ENTC Learning & Innovation Platform

### An Interactive Digital Learning Environment for Electronics Engineering

## 1. Project Overview

CircuitForge is an interactive web-based learning platform designed to enhance the learning experience of Electronics and Telecommunication (ENTC) students through structured educational content, browser-based simulations, and practical learning activities.

The platform integrates electronics learning modules, a digital logic playground, sensor simulations, knowledge assessments, coding exercises, and an interactive Circuit Mentor into a unified learning environment. It aims to bridge the gap between theoretical concepts and practical understanding by allowing students to explore engineering principles through experimentation and active participation.

## 2. Problem Statement

Traditional approaches to electronics education can make it difficult for students to visualise abstract concepts, experiment with circuit behaviour, and assess their understanding outside the classroom. Access to physical laboratory equipment may also be limited by availability, cost, or infrastructure.

CircuitForge addresses these challenges by providing an accessible, browser-based platform where students can explore fundamental electronics concepts, experiment with simulated circuit inputs and outputs, and practise technical skills without requiring dedicated hardware for every activity.

## 3. Project Objectives

* Simplify complex electronics concepts through interactive digital learning experiences.
* Improve conceptual understanding through visual demonstrations and simulations.
* Encourage independent learning, experimentation, and problem-solving.
* Provide opportunities for self-assessment through quizzes and coding exercises.
* Bring multiple electronics learning resources together in a single platform.
* Support students in developing foundational technical knowledge for further engineering study.

## 4. Key Features

### 4.1 Structured Learning Modules

Provides learning resources covering Digital Electronics, Logic Gates, Boolean Algebra, Sensors and Microcontrollers, Communication Systems, and Signal Processing.

### 4.2 Interactive Logic Playground

Enables students to experiment with digital logic gates by changing binary inputs, observing output states, and examining corresponding truth tables.

### 4.3 Sensor Simulation Lab

Demonstrates sensor-related concepts through simulated readings and interactive examples. The lab provides a way to explore sensor behaviour without requiring physical hardware.

### 4.4 Knowledge Assessment

Includes interactive quizzes that allow students to evaluate their understanding of key engineering concepts.

### 4.5 Coding Practice

Provides programming-oriented challenges to encourage logical thinking, technical practice, and problem-solving skills.

### 4.6 Circuit Mentor

Offers an interactive guidance interface to help students explore technical topics and obtain explanations while using the platform.

### 4.7 Learning Progress Tracking

Uses browser-based storage to retain supported learning activity and progress information on the student's device.

## 9. Installation and Usage

1. Clone or download this repository.
2. Navigate to the `CircuitForge` directory.
3. Open `index.html` in a modern web browser.
4. Explore the learning modules, logic playground, sensor lab, quizzes, and other available features.

No dedicated electronics hardware is required to explore the browser-based simulations.
